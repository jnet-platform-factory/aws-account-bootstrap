## Before the first deploy

1. **Create each state bucket**, once, with that account's credentials — versioned,
   encrypted, public access blocked. From any unit directory:
   `terragrunt init --backend-bootstrap`. Never do this in CI.
2. **Protect the buckets**: add them to `STATE_BUCKETS` in `bootstrap.env` and apply
   again in each account:
   ```
   STATE_BUCKETS="{{STATE_BUCKETS}}"
   ```
3. **Add protection rules** to every GitHub environment that is not for development —
   required reviewers, and deployment branches limited to `main`. They are what stands
   between a merged pull request and that account.
